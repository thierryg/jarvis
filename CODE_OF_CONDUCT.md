# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, accept feedback, focus on what is best for
the project and its users, and never harass anyone. Unacceptable behavior can be reported to
**thierry.gayet@labworks.fr**; reports are handled confidentially.
